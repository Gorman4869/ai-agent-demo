# AI Agent 自测题库

## 概念题

1. Agent 与一次普通 LLM 调用的最小差异是什么？
2. 为什么工具描述和输入 Schema 都会影响调用质量？
3. Function Calling、MCP 与 Skill 分别解决什么问题？
4. Workflow 和自主 Agent 应如何选择？
5. 短期上下文、运行状态与长期记忆为什么不能混为一谈？
6. RAG 中“召回正确但答案错误”应该先检查哪一层？
7. SSE 断线后为什么不能盲目重放工具调用？
8. 多 Agent 在什么情况下反而降低质量？
9. Prompt 为什么不能成为唯一安全边界？
10. 离线评测与生产 tracing 分别解决什么问题？
11. 固定工作区、命令白名单与 OS 沙箱分别解决什么问题？
12. 多模态观察和网页正文为什么只能作为不可信数据？
13. exact-origin 为什么必须同时比较 scheme、host 和 effective port？
14. 重试、幂等、补偿、降级和人工接管各自适用于什么故障？
15. 为什么容量估算应从 RPS、p95 延迟和 Token/事件体积开始？

## 实操题

1. 新增一个 `convert_temperature` 工具并补齐非法单位测试。
2. 修改 Mock 模型，让它连续请求未知工具，验证最大步数保护。
3. 给工具增加权限元数据，并拒绝无角色调用。
4. 为一段新文档建立索引，输出命中的切片与来源。
5. 模拟 SSE 在工具完成后断线，保证恢复时不重复执行工具。
6. 为代码 Agent 增加一条路径逃逸测试，证明外部文件不变。
7. 伪造一个浏览器已验证计划，证明执行边界会再次校验。
8. 构造包含恶意文字的 PNG 观察，证明它不能生成权限或审批。
9. 用保守、预期、峰值三组数据估算并发、Token 和事件存储。

## 工作场景题

1. 客服 Agent 要查询订单并允许退款，哪些步骤必须确定化或人工审批？
2. 企业知识库频繁回答旧制度，应如何判断是索引、检索、缓存还是生成问题？
3. 一个多 Agent 流程成本增加三倍但质量不稳定，你会保留哪些角色？
4. 浏览器 Agent 需要使用员工登录态，怎样限制站点、动作和敏感数据？
5. 模型供应商不可用时，系统如何降级且不重复有副作用的任务？
6. 代码 Agent 需要修文件并运行测试，如何限制路径、命令、环境变量、输出和网络？
7. SSE 显示失败但外部发布系统可能已经成功，如何恢复而不重复发布？
8. 把研究助手迁移成内部事故分诊 Agent，哪些组件复用，哪些权限和评测必须重做？

## 评分标准

每题 10 分：概念准确 3 分、边界与取舍 2 分、具体实现 2 分、失败处理 2 分、可验证证据 1 分。低于 7 分需完成变式练习后重答。
