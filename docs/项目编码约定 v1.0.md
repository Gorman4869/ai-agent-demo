# 项目编码约定 v1.0

## 1. 项目指纹

- 项目：AI Agent Learning UI
- 路径：`ai-agent-demo/frontend`
- 技术栈：Vue 3、TypeScript、Vite、原生 CSS
- UI、状态、路由、国际化：第一版均不引入第三方方案
- 请求封装：`src/services` 中使用原生 `fetch`

## 2. 技术与目录

- `src/components`：只包含可复用展示组件。
- `src/services`：HTTP 与 SSE 协议处理，不包含视图状态。
- `src/types`：前后端契约类型。
- `src/styles`：全局变量、重置和页面公共样式。
- `App.vue`：当前唯一页面，组合功能但不实现底层流解析。

## 3. 命名与组件

- Vue 文件使用 `PascalCase.vue`，TypeScript 文件使用 `camelCase.ts`。
- 组件使用 `<script setup lang="ts">` 和 Composition API。
- Props/Emits 使用类型声明；无深层响应需求时使用 `shallowRef`。
- 事件处理函数以 `handle` 开头，布尔值使用 `is/has/can` 前缀。

## 4. TypeScript

- 开启 strict，不使用隐式 `any`。
- API 数据先定义契约类型，再进入组件。
- 对未知错误使用 `unknown` 并通过工具函数转换消息。
- 类型导入使用 `import type`。

## 5. 样式

- 使用原生 CSS 与全局 CSS 变量，不引入预处理器或 CSS 框架。
- 页面样式集中在 `src/styles/main.css`，组件局部结构样式使用 scoped。
- 颜色、间距、圆角、阴影统一由变量管理。
- 必须保留键盘焦点、加载、错误、空状态和窄屏布局。

## 6. 请求和状态

- 所有 API 使用 `/api` 相对路径，由 Vite 代理到 FastAPI。
- 非 2xx 响应统一解析为 `ApiError`。
- SSE 只由 `services/agentApi.ts` 解析，组件只消费结构化事件。
- 当前页面状态用组合式函数管理，不引入全局 Store。

## 7. 禁止写法

- 禁止在组件中散落 URL、SSE 分帧和错误解析。
- 禁止使用 `any`、非空断言绕过契约或直接解析模型厂商流。
- 禁止新增 UI 库、状态库、请求库或字体网络依赖。
- 禁止把 API Key 放进前端环境变量或浏览器请求。
