# AI Agent 基础 12 周 + 生产补齐 14 周学习计划

## 目标与假设

目标是在 12 周内独立交付一个可解释、可测试、可恢复的 AI 研究与知识库助手。默认学习者有 Vue 开发经验、每周可投入 8–10 小时，但没有 Python 和 AI 工程基础。

原 12 周用于建立基础与工程意识；审计后的 M8–M14 再投入 14 周、每周约 8–14 小时，完成真实模型、持久化、真流式和生产作品集。工程任务以[实施计划 2.0](implementation-plan.md)为准，当前状态以[连续性状态页](continuity/status.md)为准。

## 每周训练

### 第 1 周：Agent 与语言基础

- 目标：理解 Agent 与普通聊天的差别，补齐 Python 异步、类型、JSON、异常和测试。
- 跟练：运行 Mock Agent，画出“模型决策—工具执行—结果回送”循环。
- 产出：术语卡、基础诊断、一次运行事件记录。
- 验收：能解释为什么工具执行权在程序而不在模型。

### 第 2 周：Function Calling 与手写循环

- 目标：掌握工具 Schema、注册、校验、错误和停止条件。
- 跟练：新增一个单位换算工具，补充错误参数测试。
- 产出：可复用工具模板和排错记录。
- 验收：直接回答、工具成功、未知工具、参数错误、超步数均可复现。

### 第 3 周：API、MCP 与 Skill

- 目标：理解 Function Calling、MCP、Skill 的职责差异。
- 跟练：使用 FastAPI 暴露运行接口，用 TypeScript 创建只读 MCP Server。
- 产出：接口契约、MCP 工具、Skill 说明。
- 验收：同一工具可被本地运行时和 MCP 客户端调用。

### 第 4 周：Agent 架构、上下文与 LangGraph

- 目标：掌握模型适配、运行时、状态、节点、边和 Harness。
- 跟练：用相同用例比较手写循环、SDK 和 LangGraph。
- 产出：对比报告和状态图。
- 验收：能选择确定性 Workflow 或自主 Agent，并说明原因。

### 第 5 周：Workflow 与多 Agent

- 目标：练习顺序、条件、并行、路由、汇总和人工审批。
- 跟练：实现研究员—审核员流程，并保留单 Agent 对照组。
- 产出：任务状态和质量对比。
- 验收：能证明多 Agent 带来的收益大于复杂度。

### 第 6 周：RAG 知识库

- 目标：掌握加载、切分、嵌入、检索、重排、上下文和引用。
- 跟练：为课程文档建内存索引，再迁移 pgvector。
- 产出：检索评测集、引用结果和失败分析。
- 验收：区分“没检索到”和“检索到了但回答错”。

### 第 7 周：记忆与任务推理

- 目标：区分消息历史、运行状态、用户事实和任务计划。
- 跟练：加入可删除的长期记忆与可恢复任务。
- 产出：记忆策略和污染测试。
- 验收：刷新或中断后恢复，错误记忆可纠正。

### 第 8 周：Vue Agent UI 与流式输出

- 目标：实现稳定事件协议、SSE 增量、工具状态和引用展示。
- 跟练：处理断线、失败、取消与完成。
- 产出：可演示 UI 和事件协议。
- 验收：不解析模型厂商原始流，也不重复副作用工具。

### 第 9 周：可观测性与自动化测试

- 目标：记录 run ID、节点、工具、耗时、Token、错误和成本。
- 跟练：建立固定评测集和回归阈值。
- 产出：Trace、评测报告和故障定位记录。
- 验收：能从日志定位一次失败发生在哪一层。

### 第 10 周：部署、安全与权限

- 目标：掌握 RBAC、审批、超时、取消、有限重试和 Prompt Injection 防御。
- 跟练：Docker 启动并演示越权拒绝。
- 产出：威胁模型、部署说明和安全测试。
- 验收：密钥不落库，高风险工具无法自行提权。

### 第 11 周：多模态、代码或浏览器 Agent

- 目标：理解高级 Agent 的输入、Harness 和安全隔离。
- 跟练：选择一个方向端到端实现，另外两个完成最小实验。
- 产出：扩展模块和风险清单。
- 验收：受控失败不会影响宿主环境。

### 第 12 周：系统设计与迁移答辩

- 目标：综合容量、成本、幂等、恢复、数据安全和演进路线。
- 跟练：把研究助手迁移成客服或内部运维助手。
- 产出：架构说明、演示脚本和最终复盘。
- 验收：完成最终八项现场任务。

## 每次学习的固定节奏

1. 15 分钟：不查资料回答本次诊断题。
2. 30 分钟：阅读原理并画数据流。
3. 60–90 分钟：跟练最小示例。
4. 45–60 分钟：独立完成变式练习。
5. 20 分钟：运行测试并记录故障。
6. 15 分钟：填写费曼复述和进度表。

## 最终验收

必须同时完成讲解、实操、排错、迁移和沉淀：启动 Mock 项目、新增受控工具、索引新资料、修复预置故障、展示权限拒绝、运行评测、解释架构取舍，并整理一份可复用速查表。
