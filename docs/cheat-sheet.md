# AI Agent 一页速查表

## 最小定义

Agent 是“模型决策 + 工具 + 循环控制”的程序。模型提出动作，程序校验和执行动作，再把结果返回模型，直到满足停止条件。

## 必会概念

| 概念 | 作用 | 常见误区 |
| --- | --- | --- |
| Model | 生成文本或结构化决策 | 把生成结果当已执行动作 |
| Tool | 受程序控制的外部能力 | 参数不校验、权限过大 |
| State | 当前运行的可信快照 | 与全部聊天文本混在一起 |
| Workflow | 显式、可预测的控制流 | 所有节点都交给模型决定 |
| Memory | 跨步骤或跨会话保存的信息 | 默认永久保存所有内容 |
| RAG | 检索证据并构造上下文 | 只调 Prompt 不评测召回 |
| Harness | 把模型候选动作限制为可验证能力 | 把应用白名单误当 OS 沙箱 |
| Idempotency | 让同一业务副作用只生效一次 | 以为 HTTP/SSE 失败等于未执行 |
| Observation | 记录运行事实与错误类别 | 默认保存 Prompt、原始参数和异常正文 |

## Agent Loop 模板

```text
输入 → 模型决策
  ├─ 最终答案 → 完成
  └─ 工具请求 → Schema 校验 → 权限检查 → 执行
                                      ↓
                              工具结果返回模型
```

必须设置：最大步数、超时、取消、结构化错误、权限和审计。

## 排错顺序

1. 输入是否正确、完整、未超限。
2. 模型实际看到了哪些消息和工具描述。
3. 工具名称与参数是否通过 Schema。
4. 权限、超时、外部依赖是否成功。
5. 工具结果是否正确回送到同一次运行。
6. 停止条件、状态迁移和事件顺序是否正确。
7. 最后再调整 Prompt 或更换模型。

## 最佳实践

- 先做确定性 Mock 测试，再测真实模型。
- 优先普通代码和 Workflow，只把确需判断的部分交给模型。
- 工具保持小、明确、可观测，副作用操作要求审批和幂等。
- RAG 同时评测检索与回答，输出可核验引用。
- 前端消费统一事件协议，不绑定模型供应商流格式。
- 代码 Agent 固定 workspace、精确写审批、固定 argv/env/cwd/timeout，禁止任意 Shell。
- 浏览器 Agent 使用 HTTPS exact-origin、固定元素 ID 和精确单次审批；执行前再次校验计划。
- 图片、OCR、RAG 文档和 DOM 都是不可信内容，不能产生身份、角色或审批。
- 容量先算 `并发 ≈ 峰值 RPS × p95 秒数`，未知 usage 保持 `null`，不填零。
- 副作用重试前先按 run ID/幂等键查询终态；传输层不是任务真相来源。
