# ADR-0004：建立本地 Git 基线，远程同步保持显式授权

- 状态：accepted
- 日期：2026-07-16
- 决策者：用户

## 背景

用户要求计划能跨断网和模型切换保持一致。只有文档而没有版本快照，仍难以判断某条验证对应哪一版代码。

## 决策

- 在 `ai-agent-demo` 内初始化独立 Git 仓库，默认分支为 `main`。
- 基线提交为 `9a54ebe`。
- `.gitignore` 排除虚拟环境、依赖、构建产物、密钥、本地数据库和测试产物。
- 在用户提供远程地址并明确授权前，不配置 remote，不执行 push。

## 后果

- 验证和 handoff 可以绑定 commit。
- 远程备份仍未建立，磁盘级故障风险需等远程仓库配置后消除。
