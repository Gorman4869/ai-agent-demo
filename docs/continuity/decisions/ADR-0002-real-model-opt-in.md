# ADR-0002：真实模型显式启用，Mock 作为默认验证路径

- 状态：accepted
- 日期：2026-07-16
- 决策者：用户与当前实现协作者

## 背景

课程必须覆盖真实模型的不确定性、工具调用、流式事件、usage 和错误处理，同时不能让 API Key、网络和费用成为基础学习与 CI 的前置条件。

## 决策

- 默认使用 `ManualRuntime + MockModel + 内存 Store`。
- OpenAI Runtime 只有在显式在线开关、`OPENAI_API_KEY`、模型配置和用户单次授权同时存在时才执行。
- 在线测试单独标记 `online/cost-incurring`，不得混入默认离线测试。
- 实施时从当前官方 OpenAI 文档核对 SDK、模型和工具接口，不把易漂移模型 ID硬编码为长期计划事实。

## 后果

- 离线回归稳定、无费用、可在 CI 中默认执行。
- 在线能力必须同时维护契约测试和少量真实冒烟验证。
- 没有在线验证证据时只能写 `code_complete`，不能宣称真实模型任务 `verified`。
