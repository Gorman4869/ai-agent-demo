# ADR-0001：在现有 M0–M7 上渐进补齐 M8–M14

- 状态：accepted
- 日期：2026-07-16
- 决策者：用户与当前实现协作者

## 背景

现有项目已经包含约 14,000 行源码与文档、98 项通过的后端测试、Vue UI、MCP Server、部署配置和安全实验。审计同时发现真实模型、MCP Client、持久恢复、真实 pgvector 和真流式等缺口。

## 决策

保留现有 M0–M7 产物和学习顺序，在其后新增 C0 与 M8–M14。使用兼容层和契约测试渐进迁移，不围绕单一框架重写，也不直接拆分微服务。

## 后果

- 优点：保留手写 Agent 教学价值和现有回归基线。
- 代价：迁移期同时存在旧同步链路与新异步持久 Run 链路。
- 约束：旧链路只有在新链路、Vue、文档和兼容测试全部通过后才能标记 `superseded`。

## 被否决方案

- 全量改写为 LangGraph/Agents SDK：破坏教学递进和现有测试。
- 直接微服务化：对当前单人学习项目增加无必要的运维复杂度。
